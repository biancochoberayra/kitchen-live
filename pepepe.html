La clave del Preload

El mozo tiene un menú cerrado 📋

🪑 "Quiero enviar un mensaje"
→
🤵 ✅ Está en el menúla cocina lo prepara
🪑 "Mostrame una notificación"
→
🤵 ✅ Está en el menúla cocina lo prepara
🪑 "Dame todos los archivos de la PC"
→
🤵 ❌ Eso no está en el menúel pedido ni llega a la cocina

El Preload escribe el menú antes de abrir el restaurante.
Lo que no está en el menú, para la página no existe.

// 1. Traemos las herramientas de Electron
const { app, BrowserWindow } = require('electron')
 
// 2. La "receta" para crear una ventana
function createWindow() {
  // Una ventana de 800 x 600 píxeles
  const win = new BrowserWindow({ width: 800, height: 600 })
  // Adentro mostramos nuestra página web
  win.loadFile('index.html')
}
 
// 3. Cuando Electron termina de arrancar, creamos la ventana
app.whenReady().then(createWindow)
 
// 4. Si el usuario cierra todas las ventanas...
app.on('window-all-closed', () => {
  // ...cerramos la app, salvo en Mac ("darwin"), donde queda viva en el Dock
  if (process.platform !== 'darwin') app.quit()
})
